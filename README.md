# Yogendra630 — Animated Developer Portfolio

A responsive, single-page portfolio built with HTML and CSS animations.

## Files
- `index.html` — complete portfolio page (CSS and JavaScript included)
- `assets/profile.png` — profile photo used by the page

## Run locally
Open `index.html` in a modern browser. Keep the `assets` folder next to it.

## Publish
Upload `index.html` and the `assets/` folder to a static host such as GitHub Pages.
Project cards are intentionally not linked to individual repositories until those URLs are verified.
